# User Transactions Dashboard (codesandbox)

Небольшое одностраничное веб‑приложение на PHP + SQLite для просмотра помесячных балансов транзакций между аккаунтами пользователей. Удобно для демонстрации работы с базой, тестирования агрегирующих SQL‑запросов и простого прототипа аналитики по переводам.

## Что делает
- Показывает список пользователей (из таблицы users).
- По выбору пользователя запрашивает с сервера помесячные балансы (сумма входящих минус исходящих) и отображает таблицу с месяцами и балансом.
- Простая JSON API‑точка для получения данных: `data.php?user=<id>`.

## Стек
- Языки: PHP (сервер), JavaScript (frontend), CSS
- База данных: SQLite (файл database.sqlite)
- Работа с БД: PDO (pdo_sqlite)

## Структура репозитория
```
index.php          — главная страница с формой выбора пользователя
data.php           — API: возвращает JSON с помесячными балансами для user?id=
db.php             — подключение к SQLite, init_db() для создания схемы и демоданных
model.php          — функции запроса: get_users(), get_user_transactions_balances()
script.js          — клиентский JS: fetch -> отображение таблицы
style.css          — стили страницы
database.sqlite    — файл БД (предзаполненный пример)
test.php           — отладочные/тестовые функции (run_db_test)
README.md          — этот файл
```

## Как это работает (коротко)
1. index.php выводит HTML и селект пользователей (данные берутся через `get_users()`).
2. При выборе пользователя frontend вызывает `fetch("data.php?user=<id>")`.
3. `data.php` вызывает `get_user_transactions_balances($user_id, $conn)` из `model.php`.
4. SQL в `model.php` группирует транзакции по месяцу (`strftime('%Y-%m', trdate)`) и считает баланс (входящие − исходящие) для заданного пользователя.
5. Ответ в JSON отображается в таблице на странице.

## Быстрый старт (локально)
Требования:
- PHP с поддержкой PDO и SQLite (php + php-sqlite3 / расширение pdo_sqlite)
- Права на чтение/запись для файла database.sqlite в каталоге проекта (если планируете инициализировать/перезаписать БД)

Команды:
1. (Опционально) пересоздать и заполнить БД демоданными:
   php -r "require 'db.php'; $c = get_connect(); init_db($c);"
2. Запустить встроенный PHP‑сервер:
   php -S localhost:8000
3. Открыть в браузере:
   http://localhost:8000/index.php

Проверка API:
curl "http://localhost:8000/data.php?user=10"

Возвращаемый ответ — JSON массив объектов:
[
  { "month": "2024-01", "balance": 150.00 },
  { "month": "2024-02", "balance": 200.00 },
  ...
]

## Полезные места в коде
- get_users() — model.php: SQL возвращает уникальных пользователей, у которых есть аккаунты и связанные транзакции.
- get_user_transactions_balances() — model.php: логика группировки и подсчёта баланса.
- init_db() — db.php: создание таблиц и вставка примеров данных.

## Замечания по эксплуатации и улучшениям
- Права доступа: убедитесь, что PHP процесс имеет права на запись в database.sqlite, если вы выполняете init_db().
- Безопасность: API принимает id пользователя через GET; в текущей версии это простое приложение без аутентификации — не для продакшена.
- Возможные улучшения:
  - Добавить вход/аутентификацию и разграничение доступа.
  - Отдавать помесячный отчёт с детализацией транзакций.
  - Пагинация/сортировка, графики (Chart.js) для визуализации балансов.
  - Перевести на RESTful API с валидацией входных данных.
